# صور الموقع / Site images

ضَع الصور التالية في هذا المجلد بنفس الأسماء (الأبعاد المقترحة بين قوسين):

| الملف | الاستخدام | الأبعاد المقترحة |
|---|---|---|
| `hero.jpg` | صورة القسم الرئيسي | 1000×1000 |
| `cat-1.jpg` | غرف نوم | 800×600 |
| `cat-2.jpg` | مجالس | 800×600 |
| `cat-3.jpg` | طاولات وكراسي | 800×600 |
| `cat-4.jpg` | ديكورات داخلية | 800×600 |
| `about.jpg` | قسم «من نحن» | 1000×800 |
| `project-1.jpg` … `project-6.jpg` | المعرض (1 و5 طوليتان) | 800×1100 / 800×700 |
| `og.jpg` | صورة المشاركة على وسائل التواصل | 1200×630 |

يُفضّل تصدير الصور بصيغة JPEG محسّنة (أقل من 200KB لكل صورة) للحفاظ على سرعة التحميل.
